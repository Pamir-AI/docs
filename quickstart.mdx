## Overview

The GUI came with device is still WIP (please be patient for modules to load, smashing buttons is not a good idea here XD ), we have provider some easy way for you to kick start simple "LLM controled task" . There are only a few buttons, I believe you can figure them out.

## Connect to WIFI

The only way for distiller to connect to WIFI (so you can ssh into it) is via VOICE, yes VOICE.

Once the device is powered on, go to the Wifi-use mcp server

![Screenshot 2025-05-08 at 10.59.39 PM.png](/images/Screenshot2025-05-08at10.59.39PM.png)

Try to be patient (like how u treate a 5 years old) and guide it to connect wifi for you step by step, you can start by : \
"help me scan wifi fist"

Once you see the wifi you want to connect to listed (should be the one you PC connected to), tell it the name and password.

once you successfully connected to the wifi (congrat, I know its very hard), you can ask the device to show you ssh instruction and it should guide you from there.

## How we suggest you to code

Once you know the IP address of the device, we strongly recommand link it up with cursor to create your mcp server script.

1. Download cursor here https://www.cursor.com/en on you PC
2. Select Connect via SSH 

   ![image.png](/images/image.png)
3. Type in the ssh ip provided by your device, for example 

   ![Screenshot 2025-05-09 at 11.08.24 AM.png](/images/Screenshot2025-05-09at11.08.24AM.png)
4. Once you type in the password requested and connected, wait a few minite for the cursor server to setup. 
5. You can start coding now\! we recommand giving cursor context over @llms.txt, since we tried to fit in almost all the necessary infomation in there, and mainly you should try your idea in /mcp_server
